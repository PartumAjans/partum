## Notlar
- Önerilen: kare (1:1) veya paket mockup'ı; en az 600×600 px.
- Dosya yoksa tasarımda otomatik olarak kesik çizgili yer tutucu görünür (sayfa bozulmaz).
- JPG kullanacaksanız `src` uzantısını `.jpg` olarak güncellememi söylemeniz yeterli.
